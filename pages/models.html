Train-Test Split Information

Creating a disjoint train-test split is a crucial step in machine learning. It helps ensure that the model learns from one part of the data and is evaluated on unseen data, which improves generalization and reduces overfitting.

General Strategy

  • Train Set: 80% of the data (used to train the model)
  • Test Set: 20% of the data (used to evaluate the model)
  • Stratified Sampling: Used where applicable to preserve label distribution.
  • Reproducibility: A fixed random_state ensures consistent results.

Algorithm-wise Configuration

  • Naïve Bayes: Used an 80-20 stratified split. The same split was used across all three NB types—Gaussian, Multinomial, and Bernoulli.
  • Decision Tree: Split was kept consistent across default and tuned models to allow accurate performance comparison.
  • Logistic Regression: Used the same dataset and split as Decision Tree to ensure uniform preprocessing and fair evaluation.
  • Ensemble Models: (Planned) Will follow 80-20 stratified split for consistency.
  • Support Vector Machines (SVM): (Planned) Will follow the same 80-20 rule.
